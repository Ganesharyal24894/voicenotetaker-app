The board stays as a small logo beside the name for as long as you are connected — so the thing you paired with is still visible, and the animation has an obvious destination rather than just fading out somewhere.
This is a change to the Home header: it gains a 38×46 leading slot, and the name/status block shifts right by 50 px. Battery stays where it is. Worth confirming you want that, since it alters a screen you already approved.
When disconnected, the slot holds the same board at reduced opacity with a grey status dot — so the layout does not jump between states.
In Flutter this is a Hero between the scan screen and Home, so the framework computes the flight rather than hardcoding −171/−83 — the offsets here exist only because the canvas has no layout engine to ask. Both loop here; in the app each fires once, and both collapse to a fade under reduce-motion.
